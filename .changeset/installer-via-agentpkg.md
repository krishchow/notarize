Add `npx notarize-mcp install`: an installer that copies the skills and registers the pinned MCP server for Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, OpenCode and nine other harnesses, either for the user or into one repository, with `status` and `uninstall` to match. The plugin manifests are now generated from a single `agentdist.json`.
